I built a one-page portfolio site using HTML and CSS, then initialized it as a Git repository and committed the code locally. I created a new public repository on GitHub and pushed my project to it using git push. From there, I enabled GitHub Pages in the repository settings, selecting the main branch as the deployment source. Within a couple of minutes, GitHub Pages built and published the site, making it publicly accessible at the generated URL. This gave me hands-on experience with the full Git-to-deployment workflow, from local commits to a live, hosted webpage.
